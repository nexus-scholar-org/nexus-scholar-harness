# Intent Packet Specification (`intent.json`)

When transitioning from the methodology interview to the protocol generation phase, the Copilot must produce an `intent.json` file inside `workspaces/<project-slug>/intent.json`.
This file is an `IntentPacket` which the deterministic compiler will convert into the canonical `protocol.json`.

---

## 1. Structure of `intent.json`

The file must strictly follow the Pydantic schema for `IntentPacket`. You do not generate `protocol.json` directly.

```json
{
  "project_slug": "project-name",
  "genesis_timestamp": "2026-09-01T00:00:00+00:00",
  "playbook_type": "DESIGN_SCIENCE",
  "epistemological_rationale": "Evaluating computational artifacts...",
  "primary_paradigm": "Design Science",
  "unit_of_analysis": "Computational artifacts",
  "metadata": {
    "title": "My Review Title",
    "lead_researcher": "My Name"
  },
  "research_questions": [
    {
      "text": "What evaluation metrics...",
      "target_facet": "evaluation_metrics",
      "synthesis_type": "Comparative Matrix",
      "required_evidence_type": "Quantitative benchmark scores"
    }
  ],
  "search_strategy": {
    "core_concepts": [
      {
        "concept": "Code Generation",
        "synonyms": ["code synthesis"],
        "boolean_operator": "OR"
      }
    ],
    "target_databases": ["arxiv", "semanticscholar"]
  },
  "inclusion": [
    {
      "criterion": "Paper presents a computational artifact",
      "maps_to_rq_indices": [0]
    }
  ],
  "exclusion": [
    {
      "criterion": "Papers with no empirical evaluation",
      "maps_to_rq_indices": [0],
      "reason_category": "NO_EVALUATION"
    }
  ]
}
```

### Key Differences from Full Protocol:
- IDs (`RQ1`, `INC-01`) are omitted. They are auto-generated by the compiler.
- `maps_to_rq_indices` takes integer indices (0-indexed) into the `research_questions` list, NOT the RQ string ID.
- Missing configuration fields (like `target_candidate_pool_size` or `matrix_dimensions`) are automatically populated from Playbook Presets during compilation.

## 2. Post-Generation Pipeline
After generating `workspaces/<project-slug>/intent.json`, you must invoke the compiler and renderer:
```bash
scholar-protocol compile workspaces/<project-slug>/intent.json > workspaces/<project-slug>/protocol.json
scholar-protocol render-criteria workspaces/<project-slug>/protocol.json > workspaces/<project-slug>/SCREENING_CRITERIA.md
```
