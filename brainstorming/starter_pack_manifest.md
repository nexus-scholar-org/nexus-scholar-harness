# Starter Pack Manifest: "All Possible Artifacts"
**Decision:** Maximum-value download bundle for paid students
**Status:** Designed ✅ | **Tier:** Paid

---

## Philosophy
The starter pack is the "day zero" productivity boost. A student who has just enrolled should be able to download this pack and immediately have a research infrastructure that a senior PhD student took 3 years to assemble. It is a major value driver and justification for the paid tier.

---

## Complete Artifact List

### 📁 1. Obsidian Vault — "The PhD Brain"
A pre-configured Obsidian vault implementing the Zettelkasten method (taught in Module 6.1).
- **Templates folder:** Literature note template, Permanent note template, Meeting note template, Advisor meeting agenda template
- **Daily Notes template:** Pre-built with "What I worked on / What went wrong / What's next" sections
- **Plugin configuration:** Dataview, Templater, Calendar, Kanban (pre-installed)
- **Sample notes:** 3 worked example literature notes from real papers
- **Kanban board:** Pre-configured with the 5-column Academic Kanban (Backlog / To Do / Doing / Waiting / Done)

### 📁 2. Zotero Configuration Pack
- **Exported `.csl` files:** APA 7th, IEEE, MLA, Chicago, Vancouver (the 5 most common in academia)
- **Zotero group library structure** with recommended folder taxonomy
- **Zotero Connector browser extension** setup guide (PDF)
- **BibTeX auto-export settings** file for seamless Nexus integration

### 📁 3. LaTeX Template Bundle
All slides and papers use `nexus_theme.sty` (already authored).
- `nexus_theme.sty` — the custom Beamer theme
- `thesis_template.tex` — Full PhD thesis scaffold (title page, abstract, chapters, bibliography)
- `paper_template.tex` — Single journal paper template (IMRaD structure, double-column option)
- `conference_poster_template.tex` — A0 poster template
- `cover_letter_template.tex` — Journal submission cover letter

### 📁 4. Python Notebook Bundle
One Jupyter notebook per Nexus kit, pre-loaded with boilerplate and ready to run.
- `00_setup_environment.ipynb` — Install all 6 kits, verify installation
- `01_search_kit_quickstart.ipynb` — scholar-search-kit demo
- `02_pdf_kit_quickstart.ipynb` — scholar-pdf-kit demo
- `03_graph_kit_quickstart.ipynb` — scholar-graph-kit demo
- `04_rag_kit_quickstart.ipynb` — scholar-rag-kit demo
- `05_bib_kit_quickstart.ipynb` — scholar-bib-kit demo
- `06_monitor_kit_quickstart.ipynb` — scholar-monitor-kit demo
- `07_full_slr_pipeline.ipynb` — End-to-end SLR capstone notebook

### 📁 5. Research Workflow Templates (Markdown/Word/PDF)
- `prisma_flow_template.drawio` — PRISMA 2020 editable diagram
- `synthesis_matrix_template.xlsx` — Pre-formatted spreadsheet
- `peer_review_response_template.md` — Point-by-point response letter
- `research_question_worksheet.md` — PICO/SPIDER/Heilmeier Catechism combined worksheet
- `advisor_meeting_agenda_template.md` — 4-part structured agenda (Module 6.1)

### 📁 6. PhD Kanban Board Exports
- `kanban_trello_template.json` — Importable Trello board
- `kanban_notion_template_link.md` — Notion template link
- `kanban_obsidian_md.md` — Markdown Kanban for Obsidian

### 📁 7. Shadow CV Template
- `shadow_cv_template.md` — Track rejections, desk rejects, failed grant applications (Module 6.3)

### 📁 8. Academic Profile Checklist
- `profile_setup_checklist.md` — Step-by-step: ORCID, Google Scholar, website, Twitter/X (Module 5.3)

### 📁 9. Capstone Submission Templates
- `capstone_portfolio_template.tex` — LaTeX template matching the rubric in `capstone_design.md`
- `capstone_portfolio_template.docx` — Word version for non-LaTeX users
- `capstone_checklist.md` — Self-review checklist before submitting

## Delivery Method
Single `.zip` download triggered automatically after Gumroad/LemonSqueezy payment confirmation. Hosted on a private GitHub Release or Google Drive with access controlled by email.
