# Phase F: Specialized Domain Agents

**Specification Version:** 1.0.0  
**Status:** DRAFT  
**Target System:** `scholar-agent-kit` (MCP Server), `scholar-harness`  
**Pre-requisites:** Phase 0 (Refactoring) and Phase D (Pipeline MCP Tools)  

## 1. Executive Summary

While Phase D exposes the core Nexus tools to AI via MCP (screening and orchestrator), the ecosystem's true potential lies in **Specialized Domain Agents**. This phase introduces two new agentic workflows that leverage the toolkit for high-level cognitive tasks: methodological review and visual synthesis.

### 1.1 Features Overview

| # | Feature | Kit | Impact | Effort |
|---|---------|-----|--------|--------|
| F1 | Methodology Critique Agent | scholar-agent-kit | High | Medium |
| F2 | Visual Synthesis Agent | scholar-agent-kit | Medium | Medium |
| F3 | Agent Handoff Protocol | scholar-harness | High | Low |

## 2. Feature Specifications

### 2.1 F1: Methodology Critique Agent

**Goal:** An agent that evaluates the methodological rigor of the extracted literature using `scholar-protocol-kit` (criteria) and `scholar-verify-kit` (risk of bias).

- **Workflow:**
  1. Consumes the `extracted/` markdown files.
  2. Cross-references extracted study designs with the `protocol.json`.
  3. Uses `scholar-verify-kit` tools (QUADAS-2/PROBAST) to flag risk of bias.
  4. Outputs a `methodological_critique.md` summarizing the overall robustness of the evidence base.
- **MCP Tool Addition:** `nexus_critique_methodology` (invokes the bias engines on a targeted set of DOIs).

### 2.2 F2: Visual Synthesis Agent

**Goal:** An agent that curates and explains the citation graphs and scientometric data generated by `scholar-graph-kit`.

- **Workflow:**
  1. Uses the Phase B `analyze` outputs (Hubs & Authorities).
  2. Uses the Louvain community detection outputs to identify thematic clusters.
  3. Drafts a narrative `visual_synthesis.md` that explains *why* certain papers form hubs and what each Louvain community represents conceptually.
- **MCP Tool Addition:** `nexus_graph_narrative` (reads graph stats and generates cluster summaries).

### 2.3 F3: Agent Handoff Protocol

**Goal:** Allow the `inception-agent` to seamlessly hand off execution to the `screening-agent`, which then hands off to the `synthesis-agent`.

- **Mechanism:** Standardized state files (e.g., `intent.json` → `protocol.json` → `batch_NNN.json`).
- **Orchestration:** A lightweight supervisor loop in `scholar-harness` that detects when an agent completes its phase and automatically prompts the next agent in the sequence.

## 3. Implementation Plan

1. **Phase F1:** Add the `nexus_critique_methodology` tool to the MCP server.
2. **Phase F2:** Add the `nexus_graph_narrative` tool to the MCP server.
3. **Phase F3:** Implement the handoff supervisor in `src/scholar_harness/supervisor.py`.
