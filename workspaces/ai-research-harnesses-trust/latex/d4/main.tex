\section{D4 --- Software/Artifact Paper
Scope}\label{d4-softwareartifact-paper-scope}

\textbf{Status:} v0.1 scope (2026-09-10) --- outline + claim↔build-item
mapping; drafting begins only when D1/D2 are submitted (plan §3 item 4).
\textbf{Discipline:} Phase-7 distribution work (P7.1--P7.9) becomes
\emph{content} for this paper --- build only what unblocks a paper
claim; otherwise the item is dropped (plan §5.3).

\begin{center}\rule{0.5\linewidth}{0.5pt}\end{center}

\subsection{Target venues}\label{target-venues}

\begin{itemize}
\tightlist
\item
  \textbf{Primary:} JOSS (Journal of Open Source Software) --- short,
  artifact-review format, tests + docs as the review unit.
\item
  \textbf{Alternates:} SoftwareX (Elsevier), GigaScience (Software
  track), or CS methods + arXiv paired with D2.
\item
  Acceptance criterion: the \emph{three-tier distribution} (umbrella
  package, workspace-portable CLI, universal MCP) is verifiable by a
  fresh user following the documented ``1-minute'' path.
\end{itemize}

\subsection{Working title}\label{working-title}

\emph{nexus-scholar: an agent-agnostic, provenance-verified framework
for systematic literature review}

\subsection{Paper claims (each must be anchored in a committed
artifact)}\label{paper-claims-each-must-be-anchored-in-a-committed-artifact}

\begin{enumerate}
\def\labelenumi{\arabic{enumi}.}
\tightlist
\item
  \textbf{Agent-agnostic orchestration.} One file-based workspace
  contract (\texttt{protocol.json}, \texttt{intent.json},
  \texttt{audit/journal.jsonl}, \texttt{literature/},
  \texttt{extracted/}, \texttt{synthesis/}) that any AI agent CLI or MCP
  client can drive. Evidence today: \texttt{src/scholar\_harness/cli.py}
  (status\textbar sync\textbar run\textbar export\textbar inception),
  \texttt{.agents/plugins/nexus-scholar/mcp\_config.json},
  \texttt{workspaces/*/} canonical layout.
\item
  \textbf{Append-only provenance ledger.} Every pipeline step as an
  immutable \texttt{audit/journal.jsonl} event
  (action/agent/outputs/metrics), reflected in
  \texttt{project.json}/\texttt{INDEX.md}; \texttt{batch\_log.py} +
  \texttt{log\_event.py} enforce it. Evidence: 68-event D3 ledger,
  94-event D1 ledger, \texttt{workspace-manager} skill contract.
\item
  \textbf{Deterministic claim verification.}
  \texttt{VerbatimClaimVerifier} (≥0.90 glyph-normalized coverage on
  char-window or token 6-gram alignment) as the default trust gate;
  Phase-6/Phase-4 trust streams (retraction, DAS/CAS open-science scan,
  COI audit, QUADAS-2/PROBAST RoB). Evidence:
  \texttt{scholar-verify-kit}, D2 manuscript (510/510), D3 Phase-4
  stream artifacts, D1 phase4/.
\item
  \textbf{Zero-friction distribution.} A first-time user reproduces the
  whole loop outside the monorepo: \texttt{uvx\ nexus-scholar\ init} →
  workspace scaffold → MCP wiring →
  search→screen→verify→synthesis→audit. Evidence: P7.1--P7.8 once built
  (this is the paper's validation section).
\item
  \textbf{Empirical credibility (not vaporware).} The framework has
  produced three peer-aimed deliverables: D1 UAV benchmark review
  (94-study audited corpus), D2 method paper (head-to-head vs RAG), D3
  living scoping review (58 included, 510 claims). Evidence: committed
  manuscripts + regeneration scripts in both workspaces.
\end{enumerate}
