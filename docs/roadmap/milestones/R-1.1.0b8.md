## What a tag does (three workflows)

| Workflow | On the tag `v1.1.0b8` |
| :-- | :-- |
| `publish.yml` | builds the wheel with the app's screens and publishes it to PyPI. This cannot be undone: a version number is used once. |
| `release.yml` | builds the wheel and the Claude Desktop extension and creates the GitHub pre-release with both. |
| `windows-installer.yml` | builds the bundle and the installer on GitHub's Windows runner, installs, starts, stops and uninstalls it, then its `attach` job uploads `NexusScholar-1.1.0b8-setup.exe` to the release.
