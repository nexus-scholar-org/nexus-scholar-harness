# R-1.1.0b7: release preparation and a walk of the built wheel

Branch: `dev/release/1.1.0b7` (from `origin/main` `460f23f3`, then `origin/main` `9bedf854` merged, which brought PR #305 and #306) · Lane: **RELEASE** (a version and a tag) · Status: **PREPARED, not pushed, not tagged** · Date: 2026-11-23

The researcher asked on 2026-11-23 for the next beta from the current `main`. This branch sets the version to `1.1.0b7`, adds `docs/releases/1.1.0b7.md`, corrects the guides and status lines, and records a walk of the built wheel. The coordinator session pushes the branch; the tag `v1.1.0b7` is pushed only on the researcher's word.

## Why a walk

The browser test suite was removed on 2026-11-23 (H-test-diet, PR #299), so nothing opens the app automatically. Before the tag, one person walked the packaged app once, on test data, in the desktop app's Browser pane.
