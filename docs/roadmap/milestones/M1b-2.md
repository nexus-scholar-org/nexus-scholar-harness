## Scope notes
- **Three providers** (decision 2026-11-05) supersede spec 06's "Anthropic
  only at launch": the run screen offers Anthropic (default), an
  OpenAI-compatible endpoint, and Gemini.
- The legacy Gemini path in `scholar_search/screening.py` fills a record the
  model skipped with a heuristic verdict; the new Gemini driver never does
  (a missing answer is Unclear, agent-system §1.3). The legacy path is left
  in place for the old CLI and retired at M5-slim.
- The live gate run spends the researcher's key: it is started by the
  researcher after the estimate is shown (decision 2026-11-05).

## Definition of done
- [x] **Screening task** `src/scholar_agent/tasks/screening/`: `prompt.md` (its sha256 on every proposal), the output schema sent as structured output, `task.toml` (model, effort, max tokens, batch), and a dated price table.
- [x] **Driver interface** with three drivers, all returning the same result type (ok, refusal with category, truncation, error, invalid output); a refusal, truncation, invalid output or error becomes an Unclear proposal, never Exclude and never dropped.
  - [x] Anthropic: Message Batches matched by `custom_id`, the cached protocol prefix, `output_config` format and effort, `stop_reason` handling.
  - [x] OpenAI-compatible: base URL + key, structured output where offered, else schema-checked; requests in parallel with a limit.
  - [x] Gemini: the same task over REST, no heuristic fallback.
  - [x] Driver contract tests on recorded responses, the same suite for all three.
- [x] **Keys in the OS keychain** (`nexus-scholar keys set|status|clear <provider>`); never in a workspace, config or journal file (CORE-17); the browser never takes a key.
- [x] **Consent and runs:** per-provider consent recorded in the workspace and journaled; `POST /proposals/runs` (estimate, `CONSENT_REQUIRED`, `RUN_ALREADY_ACTIVE`, per-run cost ceiling → `COST_CEILING_REACHED`), `GET /proposals/runs/{id}`, `POST .../cancel`; `AGENT_RUN_STARTED` / `AGENT_RUN_COMPLETED` journal rows with counts.
- [x] **Calibration** `POST /proposals/calibrations` (advisory; include-recall with its Wilson bound and the missed includes).
- [x] **Agreement** `GET /agreement` (decisions made before the reveal only; kappa null with its note).
- [x] **UI:** spec 06 (proposals run) and spec 07 (agreement), with their vitest and stubbed Playwright checks: `tests/screening-proposals.test.tsx`, `tests/screening-agreement.test.tsx` (the six spec-named cases), `tests-browser/screening-proposals.spec.ts` (dry run, consent, cancel, partial then resume; agreement in en and ar; light and dark). The run screen reads `GET /proposals/setup` (new, read-only: where each key is stored, never the key; the task and prompt hash; consent; the latest run). The proxy allowlist gains exactly the three run writes (`tests/console-proxy.test.ts`, with negative cases).
- [x] **Eval set:** the frozen v03 sample (644 includes + 1,000 excludes, seeded, sha256 recorded), built without writing to `workspaces/uav-crop-weed-v03`.
- [ ] **Prompt gate (live, on the researcher's key):** Opus 5.5 meets the bar; Sonnet 5.5 and Haiku 5.5 measured; the measured cost per 1,000 records replaces the estimate in agent-system §6.
- [ ] **Contract v1 baseline** current; screening API fixtures regenerated only for new routes.
