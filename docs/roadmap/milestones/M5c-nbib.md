# M5c-nbib PubMed MEDLINE `.nbib` import
Branch: dev/m5c/nbib-import · Lane: **STANDARD** as declared by the researcher (a new importer beside the RIS one and a format field in the staging records; no contract, identity or persistence-shape change: `verified.json` rows keep their shape and `SCI-` ids are derived the same way). The review (finding 1) reads `test_gate_policy.md` §lanes as requiring **RELEASE** because `POST /corpus/sources` accepts a new format, `GET /corpus` rows gain `format` and `--ris` takes `.nbib` (M5b, the same surface, was RELEASE). The lane is the researcher's decision; the closure-stage commands were run anyway and recorded in Evidence so either answer is covered · Status: IN PROGRESS · Started: 2026-11-08

Why: M5b's Deferred list ("Non-RIS formats (CSV, BibTeX, PubMed nbib): spec 11 decision 3"). PubMed is free and the most-used database in health systematic reviews, but its *Send to → Citation manager* export is MEDLINE `.nbib`, which the M5b importer could not read, so a PubMed search had to pass through a reference manager first. The researcher asked for this on 2026-11-08, after M3a-discovery (PR #204) merged. Base: `origin/main` at `e1039b1`.
