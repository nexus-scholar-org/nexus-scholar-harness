# Nexus Scholar 1.1.0b4 (beta)

This is an install fix for 1.1.0b3, released 2026-11-08. Install or upgrade:

```bash
uv tool install --force "nexus-scholar>=1.1.0b4"
nexus-scholar --version   # nexus-scholar 1.1.0b4
```

## What changed

- **The app starts after any install.** Installing 1.1.0b1–b3 with `--prerelease allow`, as the docs used to say, pulled `httpx 1.0.dev6`, a development release that drops `httpcore`. The app then stopped at start with `No module named 'httpcore'`. 1.1.0b4 keeps `httpx` below 1.0 and declares `httpcore` itself, so even that command now works.
- **The docs install with a version** (`"nexus-scholar>=1.1.0b4"`) instead of `--prerelease allow`, so only Nexus Scholar may be a beta.

Nothing else changed. The features and the local API are those of [1.1.0b3](1.1.0b3.md).

## If 1.1.0b3 or older does not start

```bash
uv tool install --force "nexus-scholar>=1.1.0b4"
```

Your workspaces are untouched: the failure happened before the app read anything.
