# GatePanel

The one place on a screen where something is written, published or approved, so a researcher always knows where the point of no return is.

## Use

- At most one per screen, bottom right of the decision column.
- `brand-soft` fill, 1.5px dashed `brand` border, `radius-lg`, padding `space-4`.
- Contents in order: a `label` in `brand` naming the gate ("WRITE GATE", "APPROVAL"), one `body` sentence saying nothing happens until confirmed, the primary button (`brand` fill, `on-brand` text, 44px tall, names the effect), then secondary buttons for "Dry run" and "Save draft" or "Defer with a reason".
- When the gate needs a pairing code, say so in the sentence; the code is entered in the panel.

## Don't

- Don't put a gate on a screen that writes nothing.
- Don't use the dashed brand border for anything that is not a gate; that is what makes it recognisable.
